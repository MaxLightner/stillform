# STILLFORM — Architecture in Context

An editorial architectural-portfolio concept by POYARA. This is a fictional practice with illustrative projects and generated visual assets; it is designed as a client-facing website demo, not a representation of completed architectural commissions.

## Experience

- The Horizon House is presented through one continuous design argument: its relationship to land, the horizontal roofline, thresholds and changing light.
- The three-step architectural narrative responds to scrolling, with direct scene selection as an alternative.
- The daylight / blue-hour comparison is keyboard- and touch-operable.
- Concept project cards open accessible native dialogs.
- Responsive editorial layout, image-first mobile view, reduced-motion support and optimized WebP assets.

## Deployment

The website is published at https://maxlightner.github.io/stillform/ from the repository root. Its source is maintained in the original Sites project.

Optimized WebP imagery is kept under `assets/`. The original high-resolution sources remain in the original Sites project for later redesigns.

## Next stage

To adapt this concept for a real architectural firm, substitute the firm's own buildings, its approved project data and corresponding multi-view imagery or 3D model, while keeping the story-driven structure.
